## ФИШКИ — включать по смыслу игры

- **Aimbot** — Lerp камеры к ближайшей цели в FOV, настраиваемая плавность, проверка команды, проверка видимости.
- **Silent Aim** — `hookmetamethod(game, "__namecall", ...)` на `Raycast` / `FindPartOnRay` / `FindPartOnRayWithIgnoreList`: подмена origin/direction на цель, `setreadonly(mt, false)` → hook → `setreadonly(mt, true)`.
- **ESP** — `Highlight` + опции Health / Distance / Name через `BillboardGui`, лимит дистанции.
- **No Recoil** — обнуление `NumberValue` с `"recoil"` / `"kick"` в имени, с бэкапом и восстановлением при выключении.
- **Fly** — `BodyVelocity` + `BodyGyro` на `HumanoidRootPart`, `SetNetworkOwner(LocalPlayer)`.
- **Speed** — `Humanoid.WalkSpeed` с восстановлением дефолта.
- **FOV-круг** — `Drawing.new("Circle")`, обновление в `RenderStepped`, скрытие при выключении.

## ЕСЛИ ИГРА ИЗВЕСТНА

- Сначала назови движок и ключевые сервисы, которые реально есть в игре (проверяемые через `game:GetService`).
