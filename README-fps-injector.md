# JakonScripts — Roblox FPS: инжектор + запуск

## 1. Что нужно

| Компонент | Что это | Где брать |
|---|---|---|
| Executor | инжектор Luau в клиент Roblox | список ниже |
| Скрипт | `jakonscripts-universal-fps.lua` | этот файл рядом |
| Roblox | версия клиента, под которую собран executor | `roblox.com/download` |

Инжектор — это отдельный `.exe`. Он подключается к процессу `RobloxPlayerBeta.exe`, поднимает Luau-стейт и даёт функции `getgenv`, `hookmetamethod`, `Drawing`, `getrawmetatable`, `setreadonly`. Без них скрипт работать не будет: часть фич (silent aim, FOV-круг) завязана именно на executor-API.

## 2. Ссылки на инжекторы

Официальные домены, живые на 2025. Каждый обновляется под свежий клиент Roblox и падает после крупных патчей Byfron/Hyperion — это норма, ждёшь апдейт.

- **Wave** — `https://waveexecutor.com` — платный (~$6/мес), стабильнее всех, обновляется первым.
- **Solara** — `https://getsolara.dev` — бесплатный, работает пачками, часто ломается после патчей.
- **Xeno** — `https://xeno.now` — бесплатный, лёгкий, хороший Luau-стейт, слабее по API.
- **Sirius** — `https://sirius.menu` — бесплатный, стабильный, из старых.
- **Delta** — `https://deltaexploits.gg` — мобильный + ПК, бесплатный.
- **Swift** — `https://swiftstudios.dev` — платный, быстрый инжект.
- **MacSploit** — `https://macsploit.com` — для macOS.
- **Статус/актуальность всех** — `https://whatexpsare.online` — таблица «кто жив, кто мёртв» после каждого патча.

Правила выбора, чтобы не поймать стилер:

- качаешь только с домена из этого списка, никогда с `mediafire`/`dropbox`/`discord` зеркал;
- установщик не должен просить отключить Defender — это красный флаг, а не «ложное срабатывание»;
- после установки проверяешь, что ярлык ведёт на тот же домен, а не на рандомный `.xyz`.

## 3. Запуск

1. Скачай инжектор, распакуй в отдельную папку, добавь её в исключения Defender.
2. Запусти Roblox, зайди в игру, дождись прогрузки карты.
3. Открой инжектор, выбери процесс `RobloxPlayerBeta.exe`, нажми **Inject** (или **Attach**).
4. Открой в инжекторе поле скрипта, вставь содержимое `jakonscripts-universal-fps.lua` целиком.
5. **Execute** (или `F5`).
6. В игре — **RightShift** открывает меню.

Если после Execute ничего не появилось — проверь консоль инжектора: чаще всего `hookmetamethod` или `Drawing` не поддерживаются, тогда silent aim и FOV-круг молча выключаются, остальное работает.

## 4. Как играть с настройками

- **Aimbot** — включи, FOV поставь 100–150, Smoothness 0.15–0.25, зажми ПКМ для наведения. Auto Shoot в конфиге есть, но по умолчанию выключен.
- **Silent Aim** — попадания идут по цели без движения камеры. Включай, когда aimbot палит.
- **ESP** — `Visuals`, лимит дистанции ставь под карту, иначе BillboardGui садит FPS.
- **Speed** — 32 безобидно, выше 60 серверные античиты (Kronos, Byfron-эвристики) ловят по дельте позиции.
- **Fly** — `Movement`, W/A/S/D + Space вверх, LeftControl вниз.
- **Unload** — `Config` → Unload. Снимает хуки, чистит Highlight и FOV-круг, возвращает WalkSpeed 16.

## 5. Что палится

| Фича | Кто ловит | Как снизить риск |
|---|---|---|
| Silent aim | серверная проверка угла камеры vs направления выстрела | hit chance 70–90, не 100 |
| Aimbot lerp | поведенческий анализ (резкие довороты) | smoothness 0.2+, FOV меньше 200 |
| Fly / Speed | дельта позиции, Humanoid.StateChanged | держи WalkSpeed ниже 60, Fly только в режимах без античита |
| ESP | ничего на клиенте, но видно на стриме/записи | Max Distance меньше, Team Color выключен |

В играх с серверным античитом (Phantom Forces, Arsenal с 2024, Frontlines) клиентские чита режутся иначе: там нужен реверс ремоутов и подмена пакетов, а не hookmetamethod. Скажи название игры — соберу билд под её движок и ремоуты.
